### About

The application is simple in concept: the user is intended to provide image links, which can be viewed, refreshed periodically and saved to disk.

Webcam Viewer as a project went through multiple private iterations, as it was the primary testbed for XeZrunner.UI, a small custom UI library that's reusable across projects.

Webcam Viewer X is the final iteration, using the latest version of the UI library.

XeZrunner.UI aims to replicate a combination of Microsoft's Fluent Design and Google's Material Design 1 in WPF.

It includes various controls, including buttons of many kinds, toggles, radio buttons and more, as well as control interaction effects and theming (i.e. dark and light themes)
